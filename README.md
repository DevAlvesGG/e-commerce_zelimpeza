# Zelimpeza — E-commerce Full Stack

Projeto de e-commerce com back-end em Node.js/Express/PostgreSQL/Prisma e front-end em React.

## Estrutura

- `backend/` — API RESTful (Node.js, Express, Prisma, PostgreSQL)
- `frontend/` — Interface web (React)
